# 故障与修复证据

## 图谱独有 ID 可能产生空正文结果

- 代码证据：原 ranker 为 graph_boost_map 的每个 ID 创建分数项，但正文仅来自向量/关键词候选，缺失时回退空字典。高图分可以让该 ID 进入结果。
- 复现条件：候选仅有 a，图谱返回未召回的 ghost 且分数很高。
- 影响：检索结果可能含空正文，无法作为答案引用依据。未声称生产实际出现过该故障。
- 确认原因：评分集合与正文候选集合不一致。
- 修复：共享 fusion 仅对已有候选加图分，保留原加权默认值；不在缺少存储检索契约时拼出虚假正文。
- 回归：test_no_graph_only_empty_document 验证 ghost 不出现；原有组件分数测试及默认数值测试验证兼容。此修复没有实现图谱额外文档加载。

## 实验环境与失败尝试

- 原官方下载在本机遇到 EOF；改用发布者镜像，并固定 revision、SHA256。未把失败下载作为成功实验。
- 继承环境的 NumPy 2.5.1 与部分编译依赖不兼容；在隔离评测 venv 内固定 NumPy 1.26.4、SciPy 1.13.1、scikit-learn 1.5.2 后完成实验，未改全局环境。
- 第一轮对照中两种调参方案的向量权重不同，不能单独归因图谱。冻结首轮参数后补同参数关图消融，并保留逐题退化与 bootstrap 区间。具体版本、样本与指标口径见 evaluation/evidence/summary.json 和 README。
